# Expense Tracker

A full-stack **Expense Tracker** web application built with **ASP.NET Core** and **C#**, featuring user authentication (login/signup) and a clean layout for tracking personal finances.

## Features

- User registration and login
- Add, view, and manage expenses
- Categorised expense entries
- Responsive layout

## Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | ASP.NET Core, C# |
| Frontend | HTML, CSS, JavaScript |
| Auth | ASP.NET Identity (login/signup) |

## How to Run

1. Clone the repo
2. Open `expenseTracker.sln` in Visual Studio
3. Build and run the project
4. Navigate to `https://localhost:{port}` in your browser
